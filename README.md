# TTP IPTV — Releases

APK pública para **Android TV** y **Fire Stick**. El código fuente no se publica aquí.

## Descargar

Abre [Releases](https://github.com/crkmlc-ui/TTP-ipTV-releases/releases) y descarga el `.apk` más reciente (`TTP-IPTV-vX.Y.Z.apk`).

## Instalar

- **ADB**: `adb install -r TTP-IPTV-vX.Y.Z.apk`
- **USB / Send Files to TV**: copia la APK al dispositivo e instala con un gestor de APK.

## Notas

- Configura tu proveedor IPTV / Xtream en la app; no incluye listas de canales.
- Builds de release **no** incluyen el botón «Demo M3U» (solo debug).
